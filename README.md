# handWarmings
These are all of little project that I do in my free time.


....... Stone Paper Scissors ......
I built this project right after finishing my beginner JavaScript course. You know that feeling when you suddenly think you're ready for anything? Yeah, that hit me too. So I decided to make a Rock-Paper-Scissors game, aiming to build a fully dynamic version of it.

When I finished, the game worked fine, but the code was a complete mess. Functions inside functions, conditions inside conditions—it felt more like a puzzle than a simple game.

So in the final phase, I handed it over to AI to clean things up. Now the code is clean, readable, and easy to extend. As a warm-up project, it's not bad at all—though getting it there wasn't exactly easy!
